# MRD × Exergio — Inventory & Device Deployment UI design

Design source for the Inventory & Device Deployment Management System, built as a
Design canvas (`canvas.json` + one `.dc.html` file per artboard).

- Live canvas (private, share from its Share menu): https://claude.ai/artifact/L2S7HS8bK12sZcEdYdviTJ
- `canvas.json` — artboard layout, pages and sizes
- `Main.dc.html` — Dashboard (entry); `DesignSystem.dc.html` — tokens, status system, components
- Other files — one screen each (Inventory, Batches, Device Preparation, Facilities, Deployments, Reports, Admin, Mobile, …)

All records shown are sample data. The `.dc.html` files depend on the canvas runtime
(`support.js`) and are not standalone pages.
