# MRD Inventory & Device Deployment System

The owner is a beginner learning full-stack development through this project. Teach as you build.

- Follow the 9-stage lifecycle in [`docs/ROADMAP.md`](docs/ROADMAP.md) in order, including its
  completion gates and the rules for moving between stages.
- Read [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md) at the start of every session; update it
  whenever a decision, test result, stage status or next action changes.
- Verify stage completion against the actual repository, never against documents alone.
- Get the owner's agreement before major architecture, database, security or hosting decisions;
  explain trade-offs in plain language first, then technically.
- One step at a time: guide the next relevant task, don't dump all stages at once.
- `design/` is the approved UI reference (Claude Design canvas files); preserve its look when
  building the real frontend. It is a prototype, not deployable app code.
